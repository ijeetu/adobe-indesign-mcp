# Security Policy

## Reporting a Vulnerability

This project controls Adobe InDesign via ExtendScript execution. While scripts are sandboxed by InDesign, please report any security concerns privately.

Contact: [create a GitHub security advisory](https://github.com/nutriandrea/adobe-indesign-mcp/security/advisories) or open a confidential issue.

## Scope

- Remote code execution via MCP
- Unsanitized ExtendScript injection
- Credential exposure in config files
- Privilege escalation through the bridge

## Response

I aim to respond within 48 hours and patch critical issues within 7 days.
